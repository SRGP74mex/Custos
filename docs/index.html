Custos

Contraseñas, frases de paso Diceware y lotes seguros — generados en tu equipo, nunca en la nube. GUI y línea de comandos en la misma app, nativa para Linux.

Passwords, Diceware passphrases and secure batches — generated on your machine, never in the cloud. GUI and command line in the same app, native on Linux.

Cómo instalarQuick Install Ver en GitHub ⭐Star on GitHub ⭐
$ git clone https://github.com/SRGP74mex/Custos.git && cd Custos && ./install.sh

Todo lo que necesitás, nada que filtrarEverything you need, nothing to leak

Aleatoriedad criptográfica con el módulo secrets de Python, cálculo de entropía y control fino sobre cada resultado.

Cryptographic randomness via Python's secrets module, entropy scoring and fine-grained control over every result.

🔑

Generador de contraseñas

Longitud de 8 a 128 caracteres, con control independiente de mayúsculas, minúsculas, dígitos y símbolos — garantiza al menos un carácter de cada categoría elegida.

Password generator

Length from 8 to 128 characters, with independent control over uppercase, lowercase, digits and symbols — guarantees at least one character from each selected category.

📝

Frase de paso (Diceware)

1024 palabras en español, 3 a 10 palabras, separador y capitalización configurables.

Passphrase (Diceware)

1024-word Spanish wordlist, 3 to 10 words, configurable separator and capitalization.

📦

Generación por lotes

Varias contraseñas o frases de una sola vez, en cantidades predefinidas.

Batch generation

Several passwords or passphrases at once, in preset counts.

🛡️

Modo seguro

Excluí símbolos problemáticos para bases de datos, o caracteres ambiguos (0, O, 1, l, I).

Safe mode

Exclude symbols that are problematic for databases, or ambiguous characters (0, O, 1, l, I).

📈

Entropía calculada

Bits de entropía y clasificación de fortaleza para cada resultado, en la GUI y en la CLI (-e).

Computed entropy

Entropy bits and a strength classification for every result, in both the GUI and the CLI (-e).

⌨️

CLI completa

Los mismos controles desde la terminal, con copiado directo al portapapeles (wl-copy / xclip).

Full CLI

The same controls from the terminal, with direct clipboard copy (wl-copy / xclip).

🔒 Privado por diseñoPrivate by design

Custos no hace ninguna llamada de red: sin telemetría, sin sincronización, sin servidor. Todo se genera con secrets (aleatoriedad criptográfica de Python) y vive únicamente en tu equipo, en el portapapeles cuando vos lo pedís.

Custos makes no network calls at all: no telemetry, no syncing, no server. Everything is generated with secrets (Python's cryptographic randomness) and lives only on your machine, on the clipboard only when you ask for it.

🚀 InstalaciónInstall

Linux de escritorio, Python 3 y python3-venv. El instalador arma su propio entorno.

Linux desktop, Python 3 and python3-venv. The installer sets up its own environment.

1

Cloná el repositorio

O descargá el ZIP desde Code → Download ZIP.

Clone the repository

Or download the ZIP from Code → Download ZIP.

2

Corré el instalador

./install.sh crea el venv, instala PySide6 y agrega el acceso al menú.

Run the installer

./install.sh creates the venv, installs PySide6 and adds the app menu entry.

3

Abrí Custos

Desde el menú de aplicaciones, o ejecutando custos en la terminal.

Open Custos

From the application menu, or by running custos in a terminal.
